## 출력 포맷의 소유권을 retriever로 옮기기

```go
type FormatHinter interface {
    OutputFormat() string
}
```

[TODO: optional interface를 선택한 이유와 기존 Retriever 인터페이스를 변경하지 않아 얻는 하위 호환성을 설명한다.]

```go
func getOutputFormat(r Retriever, fileFormat string) string {
    if hinter, ok := r.(FormatHinter); ok {
        if hint := hinter.OutputFormat(); hint != "" {
            return hint
        }
    }
    return fileFormat
}
```

[TODO: Redis/MongoDB/PostgreSQL만 JSON을 선언하고, hint가 없거나 비어 있으면 기존 global FileFormat으로 fallback하는 흐름을 설명한다.]
